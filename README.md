# Abdul Moiz — Portfolio

Professional personal portfolio website for Abdul Moiz, a fresher focused on Python, Django, and modern web development.

## Highlights

- Responsive single-page portfolio
- Python and Django focused introduction
- Skills showcase for HTML, CSS, JavaScript, React, Git, and GitHub
- Editable project cards for small projects
- Resume-friendly contact and social links
- SEO metadata and Open Graph tags

Built with React, TypeScript, Vite, Tailwind CSS, and Lucide icons.
